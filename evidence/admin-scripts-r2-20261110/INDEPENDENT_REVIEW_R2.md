## 4. Verified as correct

- Hashes match `REVIEW_SHA256SUMS` (§1). `Test-R2.ps1` reproduced **70/70 PASS**. The system snapshot was unchanged afterwards.
- `Get-ElvEffectiveMask`: ordered DACL evaluation, deny-before-grant bit logic, and generic-right mapping (GR/GW/GX/GA) are correct for the object itself.
- R-4 fix: `${script:X}:` interpolation. SID-based parsing via `RawSecurityDescriptor`.
- IPv4 complement maths: merging, unaligned CIDRs and the boundaries 0 and 2^32-1 (apart from L6). IPv6 `::2-ffff:…` excludes only `::` and `::1`.
- icacls spec strings from `ConvertTo-ElvGrant`, and the 01 strip list. These match the default ACEs of a freshly formatted NTFS root.
- `00 -SweepRoots` guards. On this host's PS 5.1.26100, `Get-ChildItem -Recurse` does not descend into child junctions (it does follow a root junction, which 00 guards against). `Remove-Item -Recurse` does **not** follow a junction, either as a child or as the item itself (scratch experiment), so the 09 folder deletes are safe from that class.
- 04: destination re-verification closes the source-swap TOCTOU. EntryScript cannot escape `bin` (it must be a listed, existing release file).
- Freeze re-hashes the copies against the source hashes (closes a swap during the copy).
- Gate order 00 → 01 → 02 → 03 → 04 is enforced in code for `-Apply`.
- Host facts read: language mode FullLanguage (SAC does not force CLM here); all firewall profiles enabled; the production task runs as `Roman`, Interactive, `RunLevel Limited`; the owner profile DACL is protected (SYSTEM, BA, Roman, plus one capability SID with 0x100020).

## 5. Not verified (elevated or `-Apply` only), ordered by risk

1. **00 `-Apply`:** DENY propagation over about 350k objects, icacls stderr and exit behaviour during propagation (M1), memory use of an unchunked mandatory sweep on a host with about 1 GB free (the first unchunked run was killed), and the post-DENY state of every object (H1).
2. **Shadow copies** of E:, F:, C:, D: (H5).
3. `secedit /configure` merge and the semantics of an empty right (02, 06, 09; L3).
4. `New-NetFirewallRule` acceptance of the range strings and `-LocalUser` SDDL. Effectiveness against SMB, WebDAV, BITS and loopback (H3).
5. diskpart on this host, mount-point persistence after reboot, drive-letter auto-assignment (L10).

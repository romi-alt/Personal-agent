## Can command filtering be bypassed? Yes.
Probes confirmed bypasses via:
- script files (`node`, `python`, `bash`, `powershell -File`);
- `powershell -EncodedCommand`;
- `cmd` caret escapes;
- variable and `$()` indirection;
- base64 piped to `sh`;
- `npm run` / `npx`;
- git aliases and `-c core.hooksPath`;
- environment manipulation (`env -u ELEVARIQ_WORKER`).

The filter is a **policy guardrail, not OS isolation**. V2 neither introduced these bypasses nor removed them. The classification and required mitigations are in SECURITY_GOVERNANCE_ASSESSMENT.md §6.
